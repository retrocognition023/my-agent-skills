# review-material-gen 使用说明

## 这个 Skill 是做什么的

把已经学过的内容整理成六种结构化复习材料，便于记忆和快速检索：

1. 一页式知识框架：层级结构或 Mermaid 图，体现知识点的从属与关联。
2. 关键词表：术语、定义、一句话通俗解释、典型示例。
3. 必背必会内容和公式：核心公式与结论，每条附使用场景。
4. 易错易混点清单：具体到什么情况容易犯什么错、哪两个概念容易混。
5. 题型与方法对应表：常见题型配步骤化的解题方法。
6. 下一步学习建议：接下来学什么、复习什么。

材料来自你实际学过的范围，不擅自扩展新知识点；需要补的前置知识会单独标注。

## 怎么触发

在学习场景里说这些话即可：复习、整理、知识框架、总结、复习材料、帮我整理。

也可以直接要求："帮我整理线性代数特征值那块的复习材料"、"出一份数据结构树与二叉树的知识框架"。

范围太宽时（比如只说"复习数学"）它会把范围追问到具体章节再动手；你也可以直接说只要其中某几种材料，不会硬凑六种。

## 触发后会发生什么

1. 先确认学科和知识点范围，顺便问一下哪些地方做过题、哪里容易卡壳。你没有提供掌握情况时，学习建议会标明是按范围推断。
2. 按顺序生成六种材料：知识框架优先用 Mermaid 图，关键词表和题型对应表用表格或编号列表。
3. 主体内容之外不重复：框架管结构、关键词表管概念、必背内容管记忆、易错点管避坑、对应表管应用、学习建议管下一步。

## 这些情况它不会启动

1. 让你整理文件、桌面、会议纪要这类非学习内容。
2. 要你逐模块讲解新知识（那是教学流程的活）。
3. 让你出练习题或做测验（那是分层出题的活）。

## 输出样式

六种材料里可以用粗体、斜体、高亮、颜色和少量 emoji 突出重点、区分层次，标题用 emoji 作锚点方便快速检索。为了保证在 Markdown、PDF、Word 里都能正常显示，只使用各载体都支持的写法：优先用粗体，颜色不单独承载信息（旁边必有文字或粗体），emoji 每段最多一两个且只用常见基础款，不使用特殊字体符号和组合型 emoji，防止乱码或显示成方框。

## 修改与验证

想调整行为，改 SKILL.md 里的规则即可。改完可用 evals\evals.json 里的场景复测，重点看三条：给了宽泛范围时是否先追问；只要一种材料时是否不硬凑六种；有没有把没学过的内容当成复习材料塞进来。
