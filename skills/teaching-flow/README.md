# teaching-flow 教学流程 Skill

一份五阶段标准化教学流程：说一句话或上传教材，就能得到教授级苏格拉底式引导教学的完整讲解。

## 怎么触发

学习场景中说这些话即可：教学流程、开始教学、讲解这个、带我学、指导、教学、老师、助学、助教、tutor、想学。

也可以先上传教材/PPT/讲义，再说"开始教学"。

## 触发后会发生什么

按五个阶段依次进行，每个阶段会明确标注：

1. 整体框架建立：说清核心主题、拆成3-5个知识模块、讲学习意义（含与 AI/ML 的联系）。
2. 逐模块深度讲解：先探测你的前置知识，缺了先补；类比引入、严谨推导、例题引导、变式推广。
3. 学习检查与追问拷问：出基础、中等、挑战三层题目。注意：出题后会停下来等你回答，不会自问自答；你答完才批改并追问。
4. 做题方法总结：考法、变形、难点、步骤模板、避坑提醒。
5. 复习材料生成：知识框架、关键词表、必背必会、易错清单、题型方法对应表、下一步建议。

其中阶段二的例题和阶段三的检查题都需要你亲自作答，这是流程的硬性纪律——先自己想，卡住了会有提示而不是直接给答案。

## 不覆盖的范围

1. 日常闲聊提到"老师""指导"等词但无学习意图时，不会启动教学流程。
2. 你明确只要快速答案、摘要或文档生成时，不强制走五阶段。
3. 本流程针对单个知识模块的完整教学；跨学科的长期学习规划、备考日程安排不在其中。

## 输出样式

讲解里可以用粗体、斜体、高亮、颜色和少量 emoji 突出重点、区分层次，方便快速抓住关键。为了保证在 Markdown、PDF、Word 里都能正常显示，只使用各载体都支持的写法：优先用粗体，颜色不单独承载信息（旁边必有文字或粗体），emoji 每段最多一两个且只用常见基础款，不使用特殊字体符号和组合型 emoji，防止乱码或显示成方框。
