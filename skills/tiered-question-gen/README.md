# tiered-question-gen 使用说明

## 这个 Skill 是做什么的

按你指定的学科和知识点，出三层难度的练习题，每层对齐 Bloom 认知层级：

1. 基础层，2-3 题：对应记忆和理解层级。考查定义、概念、基本公式的直接应用。
2. 中等层，1-2 题：对应应用和分析层级。需要两步或多步推导，涉及知识点的组合运用。
3. 挑战层，1 题：对应评价和创造层级。需要综合两个以上知识点，或逆向思维、构造性思维。

默认共 5 题（基础 2、中等 2、挑战 1）；模拟考模式为基础 3 题、中等 2 题、挑战 1 题，共 6 题。数量和要求可以在出题时直接说明。

## 怎么触发

在学习场景里说这些话即可：出题、练习、测验、考试、给我做题、模拟考、测试。

也可以直接要求："针对线性代数的特征值出练习题"、"给我做一套数据结构的模拟考"。

出题前必须说明学科和知识点。只说了其中一项时，它会先问清楚再动笔，不会自己假设。

## 触发后会发生什么

1. 先确认学科和知识点，缺了就问你，顺便问题目数量和是否要模拟考形式。
2. 按三层难度出题，每题都带六个要素：题目描述、难度层级、考查的知识点、解题所需的前置知识、标准答案、评分要点。
3. 题目先完整给出，只标注难度层级、考查知识点和前置知识；标准答案、关键步骤和评分标准统一放在最后，用分隔线隔开——方便你先自己做一遍再对答案。
4. 模拟考场景会给出建议总时长和考试规则说明（能否查资料、是否计时）。
5. 质量上有三条硬指标：题目自洽且有唯一答案（开放题除外）；中等题至少两步推导；挑战题必须综合两个以上知识点。

## 这些情况它不会启动

1. 只是要讲解某个知识点或概念。
2. 只是在聊考试焦虑、问考试安排、讨论成绩，不是要出题。
3. 要把现成的题目排版整理或直接要看答案，不需要新命题。

## 输出样式

题目和答案里可以用粗体、斜体、高亮、颜色和少量 emoji 突出重点、区分正误，方便快速抓住关键；样式只用在表达上，不会泄露答案线索。为了保证在 Markdown、PDF、Word 里都能正常显示，只使用各载体都支持的写法：优先用粗体，颜色不单独承载信息（旁边必有文字或粗体），emoji 每段最多一两个且只用常见基础款，不使用特殊字体符号和组合型 emoji，防止乱码或显示成方框。

## 修改与验证

想让行为变化，改 SKILL.md 里的规则即可。改完可以用 evals\evals.json 里的场景复测，重点看三条纪律：没给学科知识点时是否先询问；答案是否真的放在了题目后面；题目区是否做到不泄题。
