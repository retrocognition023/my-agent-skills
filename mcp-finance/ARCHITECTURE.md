# 个人财经 MCP 服务器 — 架构与实现说明

## 项目目标

构建一个可作为模板复用的自定义 MCP/连接器，让 AI 客户端能通过浏览器登录态读取某财经数据源的持仓、收益与交易信息，同时支持多个 AI 客户端（WorkBuddy / ChatGPT / Claude）。

## 关键技术决策

### 1. 小程序自动化方案不可行

现成的小程序自动化 MCP 项目（基于 miniprogram-automator 类 SDK）普遍需要目标小程序源码；目标财经平台的小程序源码不公开，无法接入。

### 2. PC 网页版方案确定

目标财经平台有 PC 网页版，可通过扫码登录，与小程序数据互通，能查看持仓、收益、交易记录。因此采用 **Playwright + Cookie 持久化** 实现自动化。

### 3. 真实 API 接口的发现方法

通过观察脚本抓包确认了若干核心接口（登录态检查、资产总览、收益分析、当日收益、产品详情）。这些接口路径写在 `src/licaitong.js`，作为示例数据源的实现；接入其他数据源时替换即可。

### 4. Session Cookie 持久化经验

- 目标平台的登录 Cookie 全部是 **Session Cookie**（`expires=-1`），浏览器关闭即失效。
- Playwright 的 `launchPersistentContext` **不会**保存 Session Cookie。
- 解决方案：用 `context.cookies()` 导出 Cookie，为每项补充 `expires` 转为持久化 Cookie，写入本地 `cookies.json`，下次启动通过 `context.addCookies()` 注入。
- 关键字段通常是用户标识、会话密钥、过期时间；具体名称随数据源而异，从抓包中识别。

## 实现结构

| 文件 | 职责 |
|---|---|
| `src/server.js` | MCP server 主入口，注册工具，处理环境变量与本地缓存 |
| `src/browser.js` | Playwright 浏览器单例管理（Cookie 注入、空闲回收） |
| `src/licaitong.js` | 示例数据源 API 封装（接口路径 + 字段解析） |
| `mcp-config.example.json` | 各 AI 客户端的配置示例（占位符，无真实路径） |
| `README.md` | 完整文档与配置说明 |

## 验证维度

一个完整实现应通过以下验证（本项目在开发中逐项实测通过）：

1. 登录态检查接口返回正确的登录标志与用户字段；
2. 持仓查询返回结构化的持仓列表；
3. 总资产 / 当日收益接口返回可解析的数值；
4. MCP stdio 通道所有工具注册成功；
5. 在各 AI 客户端的配置文件中可正确加载。

> 注：验证通过时的具体数值、账户信息、持仓明细均为隐私数据，不在公开文档中保留。

## 已知限制

1. 产品详情接口在高峰时段可能返回限流提示，稍后重试即可。
2. 当日收益接口在非交易日可能返回空数据。
3. 交易明细接口需通过观察对应页面的数据请求另行实现。
4. Cookie 有有效期（示例源约 30 天），过期需重新扫码。
5. 自动化访问应控制频率，避免触发风控。

## 后续建议

5. 把示例数据源的字段解析进一步抽象为可插拔适配器，便于接更多数据源。
